## 層ごとの実装状況

構想は 8 つの層で捉えている（[板の「やりたいこと」](../../tasks.md)参照）。入っているものの柱だけを
挙げる。1 件ずつの正確な振る舞いは各仕様書が正本。

**① オーケストレーション（並列）** — 並列タスク（worktree × カンバン・同時実行上限・完了時に
未コミットの成果を WIP コミットで保存）、セッション台帳（プロセスの外に 1 セッション 1 ファイル・
持ち主は心拍で判定・落ちたセッションの「続きから」・同じフォルダの重なり検出）、
板のウィンドウ横断共有、セッション残骸の健康診断（`session-health.mjs`＋スキル）。

**② コンテキスト可視化** — 文脈ビュー（課金モード・モデル・権限・ツール・スキル・MCP・
CLAUDE.md の階層）、CLAUDE.md タブ（階層別・節単位で開く・繰り返し指示の取り込み・リンター）、
ピン留め・予算・効率スコア、使用量（5 時間 / 週の枠を入力欄の下に常時・費用と上限アラート）、
セッションの中身（サブエージェント・フック・触ったファイル・コンパクション）。

**③ レビュー** — 承認前の差分（適用後の姿を差分エディタで・hunk 単位の部分採用）、
承認の横断キュー（全セッションぶんを危険な順に）、会話の中の承認カード（モーダルは面を
出せないときの逃げ道だけ）、同一 Wi-Fi の端末からのリモート承認、レビューの進み（見たあとに
変わったら未レビューへ戻す）、変更のようす（統計とテスト有無）、PR の説明とレビューの取り込み。

**④ 制御** — Hooks の GUI ビルダーとドライラン、承認ルールの編集とプロファイル切り替え、
実行サンドボックス、組織ポリシー（`nimbus.managedPolicy`・利用者設定の上限としてだけ効く）、
追記型の監査ログ、プラグイン API、緊急停止（全セッション一括）、危険操作の事前検知、
送信前の資格情報マスキング、秘匿ファイルの読み取り拒否、生成物への直接編集ガード。

**⑤ ラボ（スキル・プロンプト）** — スキルの一覧と曖昧検索、配れる形にする（パッケージ＋
共有マーケット）、評価（回帰・ブレ幅・モデル比較）、フロントマター補完とプレビュー実行、
セッションのスキル化、プロンプトライブラリ。

**⑥ IDE との統合（フォークの旨味）** — エージェントに渡す MCP ツール 3 系統:
`nimbus_lsp`（定義・参照・型・アウトライン・診断ほか）/ `nimbus_debug`（停止位置のスタックと
変数）/ `nimbus_git`（パス指定しか通さない・履歴を壊す操作は口に出さない）。
テストランナー連携（落ちたテストを 1 クリックで渡す）、ターミナル出力のキャプチャと再実行、
エディタから直接頼む（右クリック・CodeLens）、Git の相棒（コミットメッセージ生成・意味単位への
分割・`pull --rebase` → `push` の 1 押し・コンフリクトのその場相談）、IntelliJ 由来の基礎機能
（スクラッチファイル・Search Everywhere・Run Anything・ブックマーク・マクロ・構造検索置換・
依存構造マトリクス・Command completion・Productivity Guide）。

**⑦ 精度（読ませる・書かせる）** — 編集直後の型検証と自動ループ、シンボル単位の参照と
依存グラフ、書き方の規約を数えて渡す、リポジトリ構造の要約カード、型定義とバージョンの
自動添付、移行前後の等価性確認、ミューテーションでテストの守りを確かめる。

**⑧ 対話の質** — 着手前の確認（曖昧な指示を止める・既定 off）、仮定のリスト、見積もり表示、
選択肢の比較表、ペルソナ（ゆあ）、交代・肩越しモード、セッション中の繰り返し検出。

**見た目と運用** — Nimbus Dark / Light テーマ、日本語で読む前提の文字（typography）、
表示言語の既定を日本語に、UI の多言語化（en）、画面の置きかた（常用サイドバー＋タスク・設定・
デバッグの専用コンテナ＋下部の診断パネル）、使い始めの準備（詰まった場所に直すボタンを置く）、
配布（dmg・ad-hoc 署名・公証の手順）、ヘッドレス実行（CI から同じ判断を回す）、
リモート拡張ホストでの動作確認済み。
