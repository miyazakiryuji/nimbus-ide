# 何をしたかを並べ直す（解説モード）

記録から「どのファイルを、どの順で、なぜ触ったか」を並べ直す（T-045）。

## 何を解決するのか

エージェントの作業は速いので、**見ていても何が起きたか分からない**。あとから順を追って
並べ直すと、追える形になる。画面共有しながら開けば、そのまま説明に使える。

## 振る舞い

コマンド「何をしたかを並べ直す（解説）」（`nimbus.openExplanation`）。

- 直近 3 本の記録から、次の 3 つを順に並べる
  - **指示** — 人が出したもの
  - **なぜ** — 応答の中の理由らしい 1 文
  - **触った** — ファイルと、使ったツール
- **理由は、本人が書いた文からしか取らない。** 書かれていなければ空欄のまま
  （推測して補うと、それらしいが嘘の解説になる）
- 同じファイルを続けて触ったものは 1 つにまとめる（同じ行が並ぶと読めない）
- パスは末尾 2 つに縮める
- **いま走っているセッションには割り込まない。** 説明のために止めるのは本末転倒

## 設計

- `extensions/nimbus/src/core/explain.ts` — 並べ直しと理由の抽出（VS Code 非依存）
- `extensions/nimbus/src/explain.ts` — 記録の読み込みとコマンド

## 受け入れ条件

- [x] 理由らしい文を取り出し、無ければ作らない
- [x] 指示・理由・触ったファイルの順に並べる
- [x] 同じファイルの連続をまとめる
- [x] ファイルを触っていないターンを並べない
- [x] 推測では補わないと明記する
- [x] 画面確認: コマンドから開く
      — GUI ケース `34-report-commands.mjs`（記録が無くても開くこと。中身は各 `core/*` の単体テストで見る）

単体テスト: `extensions/nimbus/src/test/explain.test.ts`（8 件）

## 決めなかったこと・やらないこと

- **走っている最中の実況** — 説明のために処理を止めるのは本末転倒。終わってから並べ直す
- **理由の要約・言い換え** — 本人の言葉のまま出す。要約すると意味が変わる
