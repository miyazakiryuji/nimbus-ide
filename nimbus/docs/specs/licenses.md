# 依存のライセンス

配る物に何が混ざっているかを見る（T-076）。

## 何を解決するのか

配る物に何が混ざっているかは、**配ったあとでは直せない**。とくに強いコピーレフトは、
気づかずに入れると製品ごと条件が変わる。エージェントが依存を足す機会が増えるほど、
ここを見る回数は増える。

## 振る舞い

コマンド「依存のライセンスを見る」（`nimbus.openLicenses`）。

- `node_modules/*/package.json` の `license`（古い `licenses` 配列も）を読む。最大 1500 件
- **ライセンス本文は読まない。** 同じ物を何百回も読むことになるうえ、判定はどのみち人の仕事
- 4 つに分類する

  | 分類 | 例 |
  | --- | --- |
  | 緩い | MIT / Apache-2.0 / BSD / ISC |
  | 弱いコピーレフト | LGPL / MPL / EPL |
  | 強いコピーレフト | GPL / AGPL / SSPL |
  | 分からない | 記載なし・`SEE LICENSE IN …` |

- **迷ったら「分からない」に倒す。** 緩い方に倒すと「確認しなくていい」と読まれる
- `(MIT OR GPL-3.0)` のように選べる表記は、緩い方として扱う（実際に選べるため）
- 見ておいたほうがいいもの（**強いコピーレフト → 分からない**の順）を並べる

**合法かどうかは判定しない。** ライセンスの解釈は人（必要なら弁護士）の仕事で、ここは
何が入っているかを並べるだけ — と出力にも書く。

## 設計

- `extensions/nimbus/src/core/licenses.ts` — 分類と集計（VS Code 非依存）
- `extensions/nimbus/src/licenses.ts` — マニフェストの読み込みとコマンド

## 受け入れ条件

- [x] よくあるライセンスを 4 分類する
- [x] 記載が無ければ「分からない」にする（緩い方に倒さない）
- [x] 選べる表記を緩い方として扱う
- [x] 強いコピーレフトと分からないものを、その順で挙げる
- [x] 合法かどうかは判定していないと明記する
- [ ] 画面確認（実際のリポジトリで開く・未実施）

単体テスト: `extensions/nimbus/src/test/licenses.test.ts`（8 件）

## 決めなかったこと・やらないこと

- **Dart / pub の依存** — `pubspec.lock` にライセンス情報が無い。取るには別の経路が要る
- **ライセンスの互換性判定** — 組み合わせの解釈は人の仕事。機械が「大丈夫」と言うと危ない
