# 戻す道と、急ぐ道

**タスク**: T-216（ロールバックスクリプト）/ T-144（ホットフィックスの最短経路） /
**実装**: `extensions/nimbus/src/core/rollback.ts`（判定）, `extensions/nimbus/src/rollback.ts`（VS Code 層） /
**テスト**: `src/test/rollback.test.ts`

## なぜ

障害の最中に「どうやって戻す？」を考えるのが、いちばん危ない。判断力が落ちているときに、
いちばん取り返しのつかない操作をすることになる。**戻し方は、出す前に書き出しておく。**

出す前のチェックリストは T-215（`core/preflight.ts`）。ここはその**後ろ側** — 出したあとの話。

## 守っている 2 つのこと

### 1. 戻らないものを「戻る」と言わない

`git` で戻るのはコードだけ。DB のマイグレーション・投入済みのデータ・インフラや CI の設定は戻らない。
**嘘のロールバック手順は、手順が無いより悪い**（「戻したはず」で調査が止まる）。

`findIrreversible` が変更ファイルから名指しする:

| 種類 | 当たるもの | 言うこと |
| --- | --- | --- |
| `migration` | `migrations/` `db/migrate/` `prisma/migrations/` `*.sql` | コードを戻してもスキーマは戻らない。`down` の有無を先に見る |
| `data` | `seeds/` `fixtures/` | 投入済みのデータは戻らない |
| `external` | `terraform/` `infra/` `deploy/` `k8s/` `helm/` `.github/workflows/` `firebase.json` | 外側の設定はアプリを戻しても戻らない |

「たぶん大丈夫」は書かない。疑わしいものは挙げて、判断は人に渡す。

`rollbackWeight` はこの結果で重さを決める — `heavy`（マイグレーションあり）/
`careful`（他の戻らないものがある、または打ち消し）/ `light`。

### 2. 急ぐときに省いてよい段と、絶対に省かない段を分ける

「緊急だから」で落としていいのは**レビューの待ち時間とリリースノート**であって、
テストと戻し口ではない。`buildHotfixPlan` は各段に `required` を持たせ、`urgent` でも
`required: true` の段は残す。

**省かない段**（`urgentSteps`）:

1. 戻し口を先に用意する — 戻せないなら、それは急ぐ理由ではなく**止まる理由**
2. **本番に出ている版から枝を切る** — `main` から切ると未リリースの変更まで一緒に出る
3. この障害に関係する変更だけ直す
4. 直った証拠になるテストを 1 つ足す — 再発に気づける唯一の仕掛け
5. テストを通す
6. 出す
7. 直ったことを本番で確かめる
8. **既定ブランチへ戻す** — ここを忘れると次のリリースで同じ障害がもう一度出る。急ぐ道でいちばん抜ける段

**後回しにしてよい段**: レビュー、リリースノート。`urgent` では消さずに「落ち着いてから」へ畳む。

## 走らせない

出すのはスクリプトの中身と手順書まで。**実行は人が読んでから。**

`renderRollbackScript` が出す `bash` は、`--run` を付けない限り何もしない
（`set -euo pipefail` の直後で引数を見て `exit 0`）。障害中に何も考えず貼れてしまう方が危ない。
戻らないものは、スクリプトの外の作業としてコメントで先頭に出す。

## 出るもの

| コマンド | すること |
| --- | --- |
| `nimbus.prepareRollback`（戻し方を用意する） | 版を選ぶ → 差分から戻し方を組み、`shellscript` の未保存エディタに出す |
| `nimbus.planHotfix`（ホットフィックスの手順を出す） | 本番の版・直す内容・急ぐかを聞き、`markdown` の手順書を出す |

前の版（ひとつ前のタグ）があれば **出し直し**（`redeploy`）、無ければ **打ち消し**（`revert`）。
タグが 1 つも無いリポジトリでは `HEAD` を使う。

## 確認項目

- [ ] タグが 2 つ以上あるとき、選んだ版の**ひとつ下**が「戻す先」になる
- [ ] タグが 1 つも無いリポジトリでもエラーにならず、打ち消しの手順が出る
- [ ] `db/migrate/*.sql` を含む差分で「コードだけでは戻りません」が出る
- [ ] 出したスクリプトを `bash` にそのまま渡しても、`--run` が無ければ何も起きない
- [ ] ホットフィックスの枝が `main` ではなく**選んだタグ**から切られている
- [ ] 「急ぎます」でもテスト・戻し口・既定ブランチへの戻しが手順に残っている
- [ ] 「急ぎます」で省いた段が「落ち着いてから」に残っている（消えていない）
