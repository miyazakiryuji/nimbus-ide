# 多言語化（T-091）

タスクには「**`nls` に載せ替えるかの判断が要る**」と書いてある。まず数えた。

## 数えた結果

| どこ | 日本語の文字列 | 備考 |
| --- | --- | --- |
| `extensions/nimbus/src/**`（テスト除く） | **4,463 件 / 404 ファイル** | 直書き |
| `extensions/nimbus/package.json` の `contributes` | **227 件** | コマンド 154・設定 53・ビュー 13 ほか |

## 決めたこと

**`package.json` の 227 件は載せ替える。`src/**` の 4,463 件は載せ替えない。**

同じ「多言語化」でも、この 2 つは性質がまるで違う。

### なぜ `package.json` は載せ替えるのか

- **VS Code が自分で引いてくれる。** `%キー%` と書けば、起動時の言語に応じて
  `package.nls.<言語>.json` → `package.nls.json` の順に解決される。
  コードは 1 行も要らない
- **ここが最初に目に入る面。** コマンドパレットと設定画面は、
  日本語を読まない人が Nimbus に最初に触れる場所で、しかもここだけ訳せば
  「何ができる道具なのか」は伝わる
- **227 件は数えきれる。** 機械的に取り込め、取りこぼしを機械で検査できる
- **後回しにすると、訳したい人が現れても手が出せない。** 仕組みが無いと、
  貢献しようとした人は 227 件の直書きを前に諦める

### なぜ `src/**` は載せ替えないのか

- **Nimbus の値打ちは「日本語で使える」ことにある。** 英語で使いたい人には
  VS Code + Claude Code という完成品が既にある。そちらと同じ土俵に降りる理由が無い
- **4,463 件・404 ファイルの書き換えは、5 セッション並行のいま必ずぶつかる。**
  T-173（31 ファイル）ですら他セッションの未コミット行を巻き込んだ
- **訳す人が現れるまで、利用者にとって何も変わらない。**
  払うのは регресション の危険だけで、得るものは当面ゼロ
- **`vscode.l10n.t()` は束ね直しが要る。** `package.json` の `%キー%` と違い、
  ビルドに `l10n` バンドルを足す必要がある

**判断を変える条件（これが起きたら載せ替える）:**

1. `package.nls.<言語>.json` に**日本語以外の訳が実際に入り**、使っている人がいる
2. その人から「画面の中の文言も訳したい」と言われる

条件が満たされる前に載せ替えるのは、**使う人のいない機能を先に作ること**でしかない。

## 実装

- `nimbus/scripts/nls-extract.mjs` — `package.json` から `package.nls.json` へ取り込む
- `extensions/nimbus/package.nls.json` — 既定（日本語）。227 件
- `extensions/nimbus/package.nls.en.json` — 英語。227 件（**全件訳した**）

```
node nimbus/scripts/nls-extract.mjs          # 何が増えたかを見る
node nimbus/scripts/nls-extract.mjs --apply  # 取り込む
node nimbus/scripts/nls-extract.mjs --check  # 取りこぼしがあれば終了コード 1
```

### 何度でも回せるようにした理由

`package.json` は 5 セッションが同時に触る。**実際、この作業の最中にも
別セッションがコマンドを 1 つ足した**（`command.splitTerminals`）。
一度きりの変換にすると、翌日には崩れる。

`--apply` は**既に `%キー%` になっているものに触らず、増えたぶんだけ拾う**。
`--check` は CI 向けで、次の 3 つを見る:

1. 取り込まれていない日本語が `contributes` に残っていないか
2. `%キー%` に対応する既定の訳があるか（無いと画面に `%キー%` がそのまま出る）
3. **各言語ファイルに、訳の抜けと余分なキーが無いか**

3 番目が要る。**日本語だけ足して訳を忘れる**のが、いちばん普通に起きる壊れかたで、
しかも日本語で使っているかぎり誰も気づかない。

## 訳しかたの約束

- コマンド名は**単語の頭を大文字**にする（`.claude/CLAUDE.md` の UI ラベル規約）。
  4 文字以下の前置詞は、先頭と末尾を除いて小文字のまま（`from`・`with`・`in`）
- **製品名・ファイル名は訳さない** — `Nimbus`・`CLAUDE.md`・`tasks.md`
- 設定の説明は**言い切る**。日本語版が「〜します」で理由まで書いているものは、
  英語でも理由まで訳す（理由が消えると、既定値の意味が分からなくなる）

## やっていないこと

  OSS として外へ出すなら英語の `README` が要るが、これは翻訳作業であって
  仕組みの話ではないので、別に立てる
