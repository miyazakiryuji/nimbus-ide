# やり取りの切り出し

教材や登壇資料に使えるやり取りを、記録から取り出す（T-214）。

## 何を解決するのか

実際のやり取りは、作った資料よりも教材になる。**うまくいった瞬間より「なぜそうしたか」が
残っている瞬間**のほうが役に立つ。

## 振る舞い

コマンド「やり取りを切り出す（教材用）」（`nimbus.openHighlights`）。

- 記録（直近 30 本）から、指示とその直後の応答を組にする
- 選ぶ条件
  - 応答に**コードか理由**がある（200 字以上）
  - **直後に言い直しが無い** — 伝わらなかったやり取りは教材に向かない
- 長い応答を先に出す（説明が尽くされている）
- **切り出す時点で伏せる**
  - ホームのパス（＝OS のユーザー名）→ `~`
  - 鍵らしき文字列（`sk-…` / `ghp_…`）→ 伏せ字
  - **あとで消すつもりのものは、たいてい消し忘れる**
- 出すのはエディタまで。**ファイルには保存しない**（配るかどうかは人が決める）
- 出力に「配る前にもう一度目で確かめてください」と書く

## 設計

- `extensions/nimbus/src/core/highlights.ts` — 選定と伏せ字（VS Code 非依存）
- `extensions/nimbus/src/highlights.ts` — 記録の読み込みとコマンド

## 受け入れ条件

- [x] ホームのパスと鍵らしき文字列を伏せる
- [x] コードか理由がある応答だけを選ぶ
- [x] 直後に言い直しがあった組を選ばない
- [x] 長い応答を先に出す
- [x] 出力にホームのパスが残らない
- [ ] 画面確認（自分の記録で開く・未実施）

単体テスト: `extensions/nimbus/src/test/highlights.test.ts`（9 件）

## 決めなかったこと・やらないこと

- **自動で公開すること** — 記録には何が混ざっているか分からない。人が見てから
- **伏せる対象を増やすこと** — 消しすぎると何の話か分からなくなる。パスと鍵だけに絞る
