# メモリの増え方と、起動時間

**タスク**: T-222 / **実装**: `extensions/nimbus/src/core/memoryTrend.ts`,
`extensions/nimbus/src/core/startupTiming.ts`（判定）, `extensions/nimbus/src/perfWatch.ts`（VS Code 層） /
**テスト**: `src/test/memoryTrend.test.ts`

CPU の計測結果を渡すのは別（T-128 / `core/cpuProfile.ts`）。ここは**メモリと起動**。

## なぜ

どちらも「**前と比べて初めて言えること**」。

- リークは**その瞬間 1 枚では分からない**。「200MB 使っている」だけでは、多いのか漏れているのか言えない
- 起動は**一度に遅くならない**。毎回測っていれば気づくが、誰も毎回は測らない

だから、前を覚えておく。

## メモリ — 見るのは「並び」

リークの正体は「増え続けていて、戻らない」こと。同じ操作を繰り返しながら測った値の列があれば、
増え続けているかは機械的に言える。

読める形（単位は**バイトに直す**。MB と B を混ぜて比べるのがいちばん危ない）:

```
1048576              ← 1 行 1 数値
heapUsed=120 MB      ← key=value
rss: 2 MB
[{"heapUsed": 100}]  ← JSON の配列
```

**3 点未満では何も言わない。** 2 点は傾きでしかなく、リークかどうかは判断できない。

| 判定 | 条件 | 言うこと |
| --- | --- | --- |
| `leaking` | 一度も減らず、最後が最初の **1.5 倍以上** | 漏れている可能性が高い |
| `suspicious` | 1.2 倍以上、または一度も減らずに増えた | 増えているが断定はできない |
| `stable` | それ以外 | 増え続けてはいない |

**「漏れている」と言い切るのは、一度も減らずに 1.5 倍以上になったときだけ。**
GC は好きなときに走るので、途中で減っていれば「増え続けている」とは言えない。

投入する文は**数字だけを渡し、原因は決めつけない**。「どこが漏れているか」はコードを読まないと
分からないし、こちらが当たりを付けて渡すと、そこから離れられなくなる。
「心当たりが無ければ無いと言ってください」を必ず添える。

## 起動時間 — 前回との差

`flutter run --trace-startup` が置く `build/start_up_info.json` を読む（マイクロ秒 → ミリ秒）。
同じ形なら他のツールの出力でも読める。

**絶対時刻は落とす** — `engineEnterTimestampMicros` は起動の速さではなく「いつ起動したか」なので、
比べても意味がない。

**ぶれで騒がない。** 起動時間は毎回 1 割くらい動くので、**20% 以上かつ 100ms 以上**遅くなったものだけを
「遅くなった」と言う。毎回警告が出るようになった時点で、誰も読まなくなる。

基準は `workspaceState`（ワークスペースごとに違う値なので）。初回は基準として覚えるだけ。
2 回目以降は差を出し、「基準を今の値にする」で更新できる。

投入する文には **「測り直す前に直さないでください。1 回の計測はぶれます」** を入れる。

## 出るもの

| コマンド | すること |
| --- | --- |
| `nimbus.trackMemory`（メモリが増え続けていないかを見る） | 選択範囲か入力から計測列を読み、増え方を判定 |
| `nimbus.measureStartup`（起動時間を前回と比べる） | `start_up_info.json` を読み、基準と比べる |

## 確認項目

- [ ] 2 点しか無いとき「3 回以上の計測が要ります」が出て、判定は出ない
- [ ] `10MB → 20 → 30 → 40` で「漏れている可能性が高い」、`10 → 30 → 12 → 11` で「増え続けてはいません」
- [ ] `heapUsed=1 MB` と `1048576` が同じ値として読める
- [ ] `stable` のときは投入の選択肢が出ない
- [ ] 起動の初回は「基準として覚えました」で終わる
- [ ] 800ms → 850ms（6%）で警告が出ない。800ms → 1200ms（50%）で出る
- [ ] `engineEnterTimestampMicros` が一覧に出ない
