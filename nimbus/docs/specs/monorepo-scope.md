# モノレポのスコープ切り替え（T-078）

パッケージが 30 個あるリポジトリで「全部を見せる」のは、見せていないのとほぼ同じ。
探索に時間がかかり、関係ないファイルを読んで文脈を溶かし、
**別のパッケージを壊す**余地まで残る。

作業対象のパッケージだけをセッションの作業ディレクトリにすれば、そこが一度に片づく。

## 振る舞い

コマンド **「作業対象のパッケージを選ぶ」**（`nimbus.chooseScope`）:

1. マニフェスト（`package.json` / `pubspec.yaml` / `go.mod` / `Cargo.toml` …）を探して
   パッケージの根を一覧にする
2. **「リポジトリ全体」**か、パッケージを 1 つ選ぶ
3. **これから始めるセッション**が、そのディレクトリを作業ディレクトリにする

パッケージが 1 つしか無いリポジトリでは「絞り込む意味がありません」と伝えて終わる。

## 実装

- `extensions/nimbus/src/core/monorepo.ts` — パッケージの根の割り出し（純関数）
- `extensions/nimbus/src/monorepo.ts` — 探索と保存（`workspaceState`）
- `extensions/nimbus/src/extension.ts` — `workspaceCwd(scope)` が絞り込みを見る
- テスト: `extensions/nimbus/src/test/monorepo.test.ts`

## 決めたこと

**既に走っているセッションには効かせない。** 途中で足元（作業ディレクトリ）を変える方が危ない。
「これから始めるものから変わります」と、変えた瞬間に伝える。

**同じディレクトリに複数のマニフェストがあっても 1 つに畳む。** Flutter は `pubspec.yaml` と
`build.gradle` が同居するので、畳まないと同じパッケージが 2 回出る。

**既定は「絞らない」。** 何も設定していない利用者の振る舞いは、これまでと 1 ビットも変わらない。

**保存先は `workspaceState`。** どのパッケージを触っているかは、そのウィンドウの話。

## 確認すること

- [ ] モノレポでコマンドを実行すると、パッケージの一覧が出る
- [ ] 選ぶと「これからのセッションは … を作業ディレクトリにします」と出る
- [ ] 選んだあとに始めたセッションが、そのディレクトリで動く
- [ ] 「リポジトリ全体」を選ぶと元に戻る
- [ ] パッケージが 1 つのリポジトリでは、その旨が出て何も変わらない
- [ ] ウィンドウを開き直しても絞り込みが残っている

## 残っていること

- 絞り込み中であることが、ステータスバーなどに常時は出ていない（コマンドを開くと分かる）
- 並列タスク（worktree）側の作業ディレクトリには効かせていない
