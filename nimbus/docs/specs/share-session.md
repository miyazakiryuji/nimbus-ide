# やり取りを人に見せる

会話と差分を、渡せる 1 枚にまとめる（T-048）。

## 何を解決するのか

「ここで詰まっている」を伝えるのに、いちばん早いのは**やり取りをそのまま見せること**。
ただし記録には出せないものが混ざるので、そこを機械が受け持つ。

## 振る舞い

コマンド「やり取りを人に見せる形にする」（`nimbus.shareSession`）。

- 直近のやり取り（既定 10 ターン）を、**最後から遡って**載せる（困っているのはたいてい最後）
- 「何を見てほしいか」を聞く。空でも作れる（あとから書ける）
- 差分（`git diff HEAD`）を添えるかを選ぶ
- **作る前に、何が伏せられるかを見せて確認を取る**
  - ホームのパス（＝OS のユーザー名）→ `~`
  - 鍵らしき文字列 → 伏せ字
  - 「**${n} 箇所を伏せます。それ以外はそのまま載ります**」と件数と種類を出す
- 出すのは Markdown の 1 枚だけ。**どこにもアップロードしない**

**公開するかどうかは人が決めることで、機械が決めてよいことではない。**
だから「リンクを作る」ではなく「渡せる 1 枚を作る」に留める。

## 設計

- `extensions/nimbus/src/core/shareSession.ts` — 組み立てと伏せ字の点検（VS Code 非依存）
- `extensions/nimbus/src/shareSession.ts` — 記録・差分の取得と確認
- 伏せ字は [`highlights`](highlights.md) の `redact` を使い回す

## 受け入れ条件

- [x] 何が伏せられるかを種類と件数で数える
- [x] 最後のやり取りから遡って載せる
- [x] ホームのパスと、触ったファイルのパスを伏せる
- [x] 差分はあるときだけ添える
- [x] 渡す前に確かめるよう書き添える
- [ ] 画面確認（実際に作って中身を見る・未実施）

単体テスト: `extensions/nimbus/src/test/shareSession.test.ts`（8 件）

## 決めなかったこと・やらないこと

- **リンクの発行（どこかへ置くこと）** — 置いた先は消せない。渡すのは人の手で
- **伏せる対象を増やすこと** — 消しすぎると何の話か分からなくなる。パスと鍵だけ
