# CLAUDE.md のタブ

効いている CLAUDE.md を階層ごとに並べ、見出し単位で開いて直せるようにする（T-008 / T-009）。

## 何を解決するのか

CLAUDE.md は**毎セッション必ず読まれる**ので、書いた内容がそのまま精度と課金に効く。
それなのに普段はただのテキストファイルで、次の 2 つが見えない。

- **どの階層のものが効いているのか** — プロジェクトのものか、親フォルダから継承したものか、
  ユーザー設定（`~/.claude/CLAUDE.md`）か。直す場所を間違えると、他のプロジェクトまで巻き込む
- **どこに何が書いてあるのか** — 育つほど長くなり、同じ指示が二重に書かれていく

文脈ビュー（[context-view](context-view.md)）が「いま何が渡っているか」を**見せる**場所なのに対し、
ここは**直す**場所。

## 振る舞い

### 一覧（サイドバー「CLAUDE.md」）

- 効いている CLAUDE.md を、作業ディレクトリから上へ辿った順に並べる（探索は Claude Code と同じ考え方）
- 各ファイルに**出どころ**を出す

  | 表示 | 意味 |
  | --- | --- |
  | プロジェクト | 開いているフォルダ直下 |
  | 親フォルダから継承 | それより上の階層 |
  | ユーザー設定 | `~/.claude/CLAUDE.md` |

- ファイル名はプロジェクト相対、ホーム以下は `~` に短縮する（フルパスは tooltip）
- ファイルをクリックすると CLAUDE.md が開く
- 展開すると**見出し単位のセクション**が並ぶ。クリックすると**その見出しの行**に着地する
- 1 つも無いときは「CLAUDE.md がありません（「節を足す」で作れます）」と出す

### 太りすぎ・重複の指摘（T-041 の一部）

CLAUDE.md は毎ターン読まれるので、放っておくと「効いていない指示」が課金と文脈を食う。
書くのを止める必要はないが、**気づける**必要がある。

- ファイルの説明に**おおよそのトークン数**を出す（日本語混じりの散文を 1 トークン ≒ 1.5 文字で見積もる）
- 指摘があるときは、節より**先に**「N 件の指摘」を出す。クリックでその行へ飛ぶ
- 指摘する種類

  | 種類 | 何を見つけるか |
  | --- | --- |
  | 重複した見出し | 同じ節を二度作っている |
  | 中身の無い節 | 見出しだけで、読ませる価値が無いのに文脈を食う |
  | 同じ行の重複 | 同じ指示を別の場所にも書いている（12 文字以上・コードブロックの外） |
  | 長すぎる | およそ 2000 トークンを超えた |

- **価値判断はしない。**「この指示は要らない」は言わない（それは人間が決めること）。
  機械的に判断できて、直しかたが自明なものだけを出す

### 何度も言っている指示（T-041 の残り）

毎回同じことを頼んでいるなら、それは CLAUDE.md に書けば済む話。気づけないまま毎ターン
同じ前置きを打ち続けるのが、いちばん静かな無駄になる。

- 過去の記録（Claude Code 本体が残す `~/.claude/projects/…`）の**直近 20 本**から、
  自分の指示を文単位で数える。3 回以上言っているものを最大 5 件出す
- 言い回しのゆれ（記号・丁寧形の語尾）は落として同じものと見なす。**意味には踏み込まない**
- 同じメッセージの中で 2 回言っても 1 回と数える（コピペで数が跳ねないように）
- スラッシュコマンドの展開や実行結果の差し込み（`<command-name>…`）は指示として数えない。
  **実データで確認したところ、除外しないと提案の上位がこれで埋まる**
- 8MB を超える記録は飛ばす（ツリーを開くだけで固まらせない）
- 行の「→」で**その場で CLAUDE.md に足せる**。足す前に文言を直せる
  （話し言葉のままだと指示として曖昧なことが多いため）。行き先は**プロジェクトの CLAUDE.md** の
  「毎回の指示」節。節が無ければ作り、同じ内容が既にあれば足さずにその行を開く

### 節を足す

見出しの「＋」（`nimbus.addClaudeMdSection`）から、ひな形を選んで末尾に足す。

- 対象が複数あるときは、どのファイルに足すか選ぶ
- ひな形: プロジェクトの概要／コーディング規約／やってほしくないこと／よく使うコマンド／テストの方針
- **同じ見出しが既にあるときは足さず、その節を開く**。CLAUDE.md は放っておくと重複で太る場所なので、
  同じ節を二度作らせない
- 足したらその行を開いて、すぐ書ける状態にする
- CLAUDE.md がまだ無いときは、開いているフォルダ直下に作る

### 見出しの判定

コードブロック（``` / ~~~）の中の `#` は見出しとして扱わない。シェルのコメントが見出しに化けると、
実際には存在しない節が一覧に並ぶため。

## 設計

- `extensions/nimbus/src/core/claudeMdDoc.ts` — セクション解析・階層判定・表示名・追記・ひな形
  （VS Code 非依存）
- `extensions/nimbus/src/claudeMdView.ts` — ツリーと「節を足す」
- `extensions/nimbus/src/core/claudeMd.ts` — 探索（既存・[context-view](context-view.md) と共用）
- `extensions/nimbus/src/core/transcriptFiles.ts` — 記録の読み込み（[digest](digest.md) と共用）

**編集そのものは標準のエディタに任せる。** 自前のエディタは作らない（差分・元に戻す・
拡張機能がそのまま効くため）。

## 受け入れ条件

- [x] 見出し単位で展開でき、クリックでその行に飛ぶ
- [x] コードブロック内の `#` を見出しにしない
- [x] ひな形から節を足せる
- [x] 同じ見出しがあるときは重複させず、その節を開く
- [x] CLAUDE.md が無い状態から作れる
- [x] 重複した見出し・中身の無い節・同じ行の重複・長すぎるファイルを指摘する
- [x] 指摘をクリックすると該当行へ飛ぶ
- [x] 何度も言っている指示を、過去の記録から拾って出す
- [x] コマンドの展開や実行結果の差し込みを提案に混ぜない
- [x] 提案をその場で CLAUDE.md の「毎回の指示」に足せる（文言を直してから）

## 決めなかったこと・やらないこと

- **自前のエディタ（Webview）で編集させること** — 標準のエディタで足りる。差分・元に戻す・
  他の拡張機能がそのまま効く利点を捨てない
- **節の並べ替え・削除** — まずは「見える・足せる」まで。壊す操作は後回し
- **セッション中のリアルタイム提案** — 記録を読む形にしたので、走っている最中には出ない
