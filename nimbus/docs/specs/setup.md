# 使い始めの設定

言語に合わせた設定と、揃っているかの確認（T-203 / T-204）。

## 何を解決するのか

最初の設定は、**何を決めればいいのか分からない**のが本当の壁。項目を並べて「好きに設定して
ください」と言われても、初めての人は決められない。

## 振る舞い

コマンド「使い始めの設定をする」（`nimbus.runSetupWizard`）。

- **揃っているかを先に出す** — Claude Code が見つかっているか／フォルダを信頼しているか／
  CLAUDE.md があるか／言語の設定が入っているか
  - できていない項目には**必ずやることを添える**。できていないことだけを並べない
  - **全部そろっていなくても始められる**と書く（順にやらせない）
- リポジトリの中身から言語を当てる（`pubspec.yaml` → Flutter、`go.mod` → Go ほか）。
  **Flutter と Node が同居していたら Flutter**（重いほうに合わせる）
- プリセットを選ぶと、入る設定と CLAUDE.md の節を**すべて見せてから**書く
  - **黙って設定を変えない。**「気づいたら設定が変わっていた」がいちばん信用を失う
- どのプリセットにも安全の設定（承認前の差分・秘匿ファイルの遮断）が入る
- 書く先はワークスペース設定。**グローバルは触らない**（他のプロジェクトを巻き込まない）

## プリセット

| 言語 | 入るもの |
| --- | --- |
| Flutter / Dart | ビルドコマンド、生成物を直接編集しない・`pub get` / `pod install` の決まり、文言は `.arb` へ |
| Node / TypeScript | ビルドコマンド、`any` で潰さない、依存を足す前に標準機能を見る |
| Go | `go test` / `go vet`、エラーを握りつぶさない |
| Swift / iOS | `project.pbxproj` を手で編集しない |
| そのほか | 概要の節だけ |
