# 依存構造マトリクス（DSM）

## 何を解決するのか

「このフォルダを触ると、どこに響くのか」が分からない。import を 1 本ずつ追っても全体の形は見えず、
**循環依存**にいたっては見つける手段が無い。IntelliJ IDEA の DSM と同じく、
フォルダ間の依存を行列にして、循環を名指しする。

## 振る舞い

### コマンド

コマンドパレットの `Analyze: Show Dependency Structure Matrix`。

### 手順

1. **グループの粗さ**を選ぶ（2 階層 `src/vs` / 3 階層 `src/vs/base` / 4 階層 `src/vs/base/common`）
2. ワークスペースのソースを走査（進捗は通知に出る・中断可）
3. レポートが新しいエディタタブに開く

### レポートの中身

**循環が先、行列が後。** 循環が「発見」で、行列はその根拠だから。

```
Dependency Structure Matrix
===========================

Folders: 12   Files scanned: 843   Grouped at depth: 3

Cycles: 1
  - src/vs/base  <->  src/vs/platform

Rows depend on columns. A dash is the folder itself; a dot is no dependency.

            1  2  3
1. src/a    —  2  .
2. src/b    .  —  4
3. src/c    1  .  —
```

- 行が列に依存する。数字は import の本数
- `—` は自分自身、`.` は依存なし
- 列は番号で、対応するフォルダ名は各行の頭に出る（フォルダ名は列見出しには長すぎる）

### 何を数えるか

| 対象 | 扱い |
|---|---|
| `.ts` `.tsx` `.mts` `.cts` `.js` `.jsx` `.mjs` `.cjs` | 走査する |
| `import ... from`・副作用 import・`export ... from`・動的 `import()`・`require()` | すべて拾う |
| 相対指定（`./` `../`） | 解決して辺にする |
| ベア指定（`react`・`vs/base/common/uri` などのエイリアス） | **辺にしない** |
| 同じフォルダ内の import | 数えない（フォルダは自分自身に依存する） |

**ベア指定を辺にしないのは、解決できないものを推測すると行列に架空の辺が載るから。**
パッケージ依存やエイリアス解決はこの機能の対象外だと割り切っている。

### 上限

2,000 ファイルで打ち切る。打ち切った場合は**レポートの冒頭にその旨を明記する**
（黙って切ると「全部見た」と読めてしまう）。

### エラー・境界

- フォルダを開いていないときは案内を出す
- 読めないファイルは黙って飛ばす（1 件で全体を止めない）
- ワークスペースの外へ出る相対指定は辺にしない

## 設計

| ファイル | 役割 |
|---|---|
| `contrib/dependencyMatrix/common/dependencyMatrix.ts` | import 抽出、相対指定の解決、フォルダキー化、行列構築、**循環検出（反復版 Tarjan）**、整形 |
| `contrib/dependencyMatrix/browser/dependencyMatrix.contribution.ts` | ファイル収集・読み込み・進捗・レポートを開く |
| `contrib/dependencyMatrix/test/common/dependencyMatrix.test.ts` | 純粋関数のテスト（7 件） |

循環検出は**強連結成分のうち要素数 2 以上**を取る。Tarjan を再帰ではなく明示スタックで
書いてあるので、深いグラフでもスタックを溢れさせない。

読み込みは 50 件ずつ並列。

### 配色について

独自 CSS なし。レポートは等幅のプレーンテキストとしてエディタで開くので、
テーマ（T-001 の Claude 配色）にそのまま乗り、検索もコピーもできる。

## 受け入れ条件

- [ ] コマンドを実行すると粗さのピッカーが出る
- [ ] 進捗通知に読み込んだ件数が出て、中断できる
- [ ] レポートがエディタタブに開く
- [ ] 循環があれば `A <-> B` の形で名指しされる
- [ ] 循環が無ければ `Cycles: none.` と出る
- [ ] 行列の桁が揃っていて、`—` と `.` が読み分けられる
- [ ] 粗さを変えるとフォルダの数が変わる
- [ ] 2,000 件を超えるリポジトリで打ち切りの注記が出る

確認記録は `../testing/dependency-matrix.md`。

## 決めなかったこと・やらないこと

- **対話的な行列ビュー（クリックで絞り込み）は作らない** — webview が要る。
  まずテキストで「循環がどこにあるか」を answer できるかを確かめる
- **TypeScript の path エイリアスは解決しない** — `tsconfig.json` の読み解きが要る。
  この repo のように `vs/...` で参照する形は辺にならない点は仕様として明記した
- **JVM・Python・Go は対象外** — import の形が違う。需要が出たら抽出器を足す
- **循環の「どの import が原因か」までは出さない** — フォルダ単位の発見までが目的。
  特定は構造検索（T-229）や LSP（T-098）の仕事
