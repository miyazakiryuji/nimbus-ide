# 定型プロンプトと、横断的な「探す」

## 何を解決するのか

**定型**（T-035）— 「このファイルをレビューして。観点は…」のような指示は、
毎回打ち直すには長すぎて、覚えておくには細かすぎる。

**探す**（T-117）— スキルは F6 で探せるようになったが、サブエージェント・
スラッシュコマンド・MCP ツールは `contextView` に名前が並ぶだけで、
**探せないし、そこから使えない**。覚えている人しか使えない機能は、無いのとあまり変わらない。

## 振る舞い

### 定型プロンプト（T-035）

コマンド **「Nimbus: 定型プロンプトを使う」**（`nimbus.prompts`）。

- `{{対象ファイル}}` のように変数を空けて保存し、呼び出すときに**順に聞かれる**
- 変数は**本文に出てきた順**に聞く（書いた人の意図がその順なので、並べ替えない）
- 同じ変数が複数箇所にあれば、全部埋まる
- **埋め残しは空文字にせず `{{名前}}` のまま残す。** 空にすると、何が抜けたか
  分からないまま送られる。送る前に「埋まっていない変数があります」と一度聞く
- 途中でやめたら送らない（半端に埋まったものを送るほうが困る）
- 出荷時に 3 つ入っている（レビューを頼む / バグを調べる / テストを足す）。
  **空から始めさせない** — 変数の書き方は例が 1 つあれば伝わる
- 追加・削除は「定型プロンプトを管理する」（`nimbus.managePrompts`）

### 横断的な「探す」（T-117）

コマンド **「Nimbus: 探す」**（`nimbus.findAnything`）。

スキル・スラッシュコマンド・サブエージェント・MCP ツール・定型プロンプトを
**1 つの入口**から絞り込む。

- **名前だけでなく説明にも当てる**（「PDF」で探したいのに名前が `docx-tools` のことがある）
- 当たった場所で点数を変える。完全一致 → 前方一致 → 部分一致 → 説明への一致
- 説明への一致は、**語を全部含むときだけ**拾う（1 語かすっただけで出さない）
- 選ぶと「コックピットで使う」か「ファイルを開く」（ファイルがあるものだけ）
- **送る文は種類で変える**。スキルとコマンドは `/名前` で直接撃てるが、
  サブエージェントと MCP ツールは撃てないので「使ってください」と頼む形にする

## 設計

- `extensions/nimbus/src/core/promptLibrary.ts` — 変数の抽出と差し込み。VS Code 非依存
- `extensions/nimbus/src/core/findAnything.ts` — 採点と並び順、送る文の作り分け。VS Code 非依存
- `extensions/nimbus/src/extension.ts` — フォームと QuickPick、直近 init の保持

探す対象のうち、コマンド・サブエージェント・MCP ツールは **`session-init` からしか
分からない**（Claude Code 側が持っている情報なので）。そのため直近の init を保持し、
セッション開始前は「探せるものがまだありません」と出す。

### `core/sessionPresets.ts` との違い

`sessionPresets` の `{input}` は「入力を 1 つ差し込んでセッションを**始める**」もの。
こちらは「名前つきの変数を複数埋めて、**いまのセッションへ送る**」もの。
似ているが、埋める体験（1 行 / フォーム）も送り先も違うので分けてある。

## 受け入れ条件

- [x] 変数を出てきた順に、重複なく拾う（単体テスト）
- [x] 同じ変数が全部埋まる（単体テスト）
- [x] 埋め残しを空文字にせず、そのまま残す（単体テスト）
- [x] 空文字を入れたら「埋めていない」扱いにする（単体テスト）
- [x] 出荷時の定型が変数の書き方の例になっている（単体テスト）
- [x] 名前への一致を説明への一致より上に出す（単体テスト）
- [x] 説明への一致は語を全部含むときだけ（単体テスト）
- [x] 送る文を種類で変える（単体テスト）
- [ ] 画面確認: 定型を選んでフォームに答え、送られる
- [ ] 画面確認: 「探す」から MCP ツールが引ける（セッション開始後）

## 決めなかったこと・やらないこと

- **`@` でのファイル／シンボル参照補完は入れていない**（T-035 の後半）。
  QuickPick の入力欄に補完を差し込む口が VS Code 側に無く、
  自前の入力 UI（Webview）を作る話になる。定型の本体とは別の仕事なので分けた
- **定型をファイルとして保存しない。** `globalState` に持つ。
  リポジトリに配りたくなったら T-043（設定のパッケージ配布）の仕事
- **MCP ツールを一覧から直接実行しない。** それは T-235（ツールの単体実行）
