# 環境の食い違い

リポジトリが求めている版と、手元の版を突き合わせる（T-205）。

## 何を解決するのか

リポジトリは**どの版で動かすつもりか**をどこかに書いている。それと手元がずれていると、
**エラーは全然関係ない場所に出る**。突き合わせれば分かることなので、先に見せる。

## 振る舞い

コマンド「環境の食い違いを見る」（`nimbus.openEnvCheck`）。

- 求めている版を集める

  | 場所 | 読むもの |
  | --- | --- |
  | `.nvmrc` | Node の版 |
  | `package.json` の `engines` | 各道具の下限 |
  | `pubspec.yaml` の `sdk` | Dart の下限 |
  | `.tool-versions` | asdf 形式の一覧 |

- 手元の版は、実際にコマンドを叩いて取る（`node --version` など）。**失敗しても止めず**、
  「見つかりません」として扱う（入っていないことも情報）
- **パッチ違いでは騒がない。** メジャーとマイナーまで見る
- **どちらに合わせるべきかは言わない。** 手元を上げるのか、リポジトリの要求を下げるのかは
  状況による。「エラーが関係ない場所に出ているときは、まずここを疑ってください」まで
- 記載が見つからないときは、どこを見ているかを書く（探し方が分かるように）

## 設計

- `extensions/nimbus/src/core/envCheck.ts` — 収集・比較・表示（VS Code 非依存）
- `extensions/nimbus/src/envCheck.ts` — ファイル読み込みとコマンド実行

`dart` や `go` は版を stderr に出すことがあるので、両方見る。

## 受け入れ条件

- [x] 4 種類の場所から求めている版を集める
- [x] 制約（`>=3.4.0 <4.0.0`）から下限を取り出す
- [x] 読めない `package.json` を黙って飛ばす
- [x] パッチ違いで騒がない
- [x] 入っていない道具を「見つかりません」にする
- [x] どちらに合わせるかは言わない
- [ ] 画面確認（実際の環境で開く・未実施）

単体テスト: `extensions/nimbus/src/test/envCheck.test.ts`（8 件）

## 決めなかったこと・やらないこと

- **版の自動切り替え** — `nvm` や `asdf` の状態を壊す。人が決める
- **上限の判定** — 上限を超えていても動くことが多く、騒ぐと読まれなくなる
