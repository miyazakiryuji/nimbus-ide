# 文脈の可視化

「いま Claude に何が渡っているのか」を一覧するツリー（旧 F-2 / フォーク F3）。

## 何を解決するのか

モデル・作業ディレクトリ・使えるツール・読み込まれる CLAUDE.md といった前提が見えないと、
出力の良し悪しを判断できない。同じ指示で結果が違うとき、たいてい違っていたのは前提の方。

## 振る舞い

サイドバー「文脈」に、セッション開始時の init メッセージから得られる**事実だけ**を並べる。
推測や集計はここでは出さない。

| 項目 | 内容 |
| --- | --- |
| 課金モード | サブスク利用／API キー利用／接続未確認（[sessions](sessions.md)） |
| モデル | init が返したモデル名 |
| 作業ディレクトリ | セッションの cwd |
| 権限モード | `permissionMode` |
| Claude Code | 実行中の Claude Code のバージョン |
| ツール | 使えるツールの一覧（件数つき） |
| スキル | 使えるスキルの一覧 |
| スラッシュコマンド | 使えるコマンドの一覧 |
| サブエージェント | 使えるサブエージェントの一覧 |
| MCP サーバー | 名前と接続状態 |
| プラグイン | 名前とバージョン |
| CLAUDE.md | 作業ディレクトリから上へ辿って見つかったもの＋ユーザー設定。**それぞれに出どころ**（プロジェクト／親フォルダから継承／ユーザー設定）を添える |

- セッション開始前は「セッションを開始すると、ここに文脈が表示されます」と出す
- CLAUDE.md はホームディレクトリを `~` に短縮して表示する（実パスは tooltip）

## 設計

- `extensions/nimbus/src/contextView.ts` — ツリー（`TreeDataProvider`）
- `extensions/nimbus/src/core/claudeMd.ts` — CLAUDE.md の探索（VS Code 非依存）

CLAUDE.md の探索は Claude Code 本体と同じ考え方（cwd から上へ辿り、加えて `~/.claude/CLAUDE.md`）。

## 受け入れ条件

- [x] セッション開始後、init 由来の項目がすべて出る
- [x] CLAUDE.md が cwd から上へ辿って集まり、ユーザー設定も拾える
- [x] 各 CLAUDE.md に出どころ（プロジェクト／親フォルダから継承／ユーザー設定）が出る
- [x] 課金モードが `apiKeySource='none'` でサブスク表示になる
- [ ] 画面確認（`nimbus/docs/testing/f3-f6.md` §6・未実施）

確認記録: `nimbus/docs/testing/f3-f6.md` §2
