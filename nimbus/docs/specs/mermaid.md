# Mermaid の図を確かめる

描く前に、落ちる書き方を見つける（T-061）。

## 何を解決するのか

エージェントが描いた図は、**構文が通らないと何も出ない**。エラーは「Parse error on line 3」の
形で、どこが悪いかは分かっても**何が悪いか**は分からない。

## 振る舞い

コマンド「Mermaid の図を確かめる」（`nimbus.checkMermaid`）。

- 開いている Markdown から ```mermaid の塊を取り出す
- **よくある間違いだけ**を、直しかたつきで出す

  | 見るもの | 直しかた |
  | --- | --- |
  | 先頭が図の種類でない | `graph TD` / `sequenceDiagram` などから始める |
  | ラベルの中の括弧 | `A["文字 (注)"]` のように `"` で囲む（いちばんよく踏む） |
  | 全角の矢印・記号 | `-->` と半角の `-` にする |
  | 大文字の `End` | 小文字の `end` にする |
  | 中身が空 | 種類から書き始める |

- **問題が無ければ、報告より先にプレビューを開く**（見たいのは図であって報告ではない）
- 描画は VS Code の Markdown プレビューに任せる。**レンダラは同梱しない**
  （重いうえ、本家より良くはならない）

**構文解析はしない。** Mermaid の文法は種類ごとに違い、追いかけると保守できない。
「これをやると必ず落ちる」と分かっているものだけを見る。
