# 手元の端末から承認だけする

**タスク**: T-054（スマホから承認だけ）/ T-086（iPad から様子見）/
**実装**: `extensions/nimbus/src/core/remoteApproval.ts`（判定と画面）,
`extensions/nimbus/src/remoteApproval.ts`（VS Code 層） / **テスト**: `src/test/remoteApproval.test.ts`

## なぜ

いちばん多い時間の損は、**進んでいないことに気づいていない時間**。
席を立った 1 時間、エージェントは最初の承認待ちで止まっていた、が実際に起きる。

承認だけなら、机の前にいなくてもできる。

## この口は危ない、という前提で作る

**エージェントに何かをさせる口**なので、緩いと事故る。設計で守っているのは 5 つ。

| 守ること | どうやって |
| --- | --- |
| 既定では開かない | 常駐させない。`nimbus.toggleRemoteApproval` を押したときだけ動く |
| 合言葉が要る | 開くたびに 16 バイトを作り直す。**前に開いた URL は次には効かない** |
| できるのは承認だけ | 通る道は 3 つ（画面・一覧・答える）。指示は送れない・履歴は読めない・ファイルは見られない |
| 開きっぱなしにしない | 10 分使われなければ自動で閉じる |
| 外向きには開かない | `0.0.0.0` ではなく、**同じ Wi-Fi の中で見える IPv4 アドレスにだけ結ぶ** |
| 危ないものは許可させない | `danger` は**拒否だけ**。一覧には出すが「許す」を出さない |

補足:

- **合言葉は道の先頭**（`/<token>/api/list`）。クエリだとログや履歴に残りやすく、`Referer` で外へ漏れる経路がある
- **合言葉が合わないものには 404 を返す** — 401 だと「合言葉さえ合えば何かある」と教えることになる
- **答えるのは `POST` だけ。** `GET` で状態が変わると、先読みや履歴の再訪で勝手に承認される
- 画面は **外に何も取りに行かない**（CSP `default-src 'none'`。同じ Wi-Fi の中では CDN が届かないこともある）
- 要約は**渡す前に escape**する（画面側でそのまま入れるので）

## `danger` は、ここからは許可できない

モーダルでの承認は「差分エディタを横に開いてから聞く」ことが前提で、`Write` の承認は
**中身を見た上での判断**。手元の端末には差分が出ないので、同じ「許可」でも**判断の質がまるで違う**。

`normal` / `caution` なら「テストを通す」程度なので画面外でも判断できるが、
`danger` は「何が起きるか」を読まないと決められない。

もう 1 つ。この層は `danger` の自動許可の経路を**すべて塞いである**
（`autoApproveReadOnly` も、セッション内の「常に許可」も、保存済みルール（T-038）も、
生成物ガード（T-139）も、例外なく `danger` を素通りさせない）。
**遠隔だけが抜け道になると、その一貫性が崩れる。**

- **一覧からは隠さない。** 隠すと「なぜ止まっているのか分からない」状態になり、
  この機能が解決したかった「気づかず 1 時間ロス」に戻ってしまう
- 画面には「ここでは断るだけです（許可は差分を見てから）」と出す
- **画面でボタンを出さないだけでは守りにならない。** 通す側でも `403` で断る
- 遠隔から渡す答えは **`allow` と `deny` だけ**。`allow-session` / `always-allow` は
  「以後聞かない」を作るので、差分を見られない場所から設定を永続化させない

## 見せかた

| すること | どうしているか |
| --- | --- |
| 並び | 危ないものを先に、同じ危なさなら**待っている順**に |
| 待ち時間 | 「たった今 / N 分待ち / N 時間待ち」。**秒は見せない**（1 秒ごとに変わる数字は落ち着かない） |
| 危なさ | 「要注意 / 確認 / 軽い」の 3 段（`core/risk.ts` の言い方をそのまま持ち込まない） |
| ボタン | 「断る」「許す」の 2 つだけ |

一覧は 2 秒ごとに取り直す。圏外のときは黙って次の周回で拾う（エラーを出しても押す先が無い）。

## 出るもの

| コマンド | すること |
| --- | --- |
| `nimbus.toggleRemoteApproval`（手元の端末から承認だけできるようにする） | 開く／開いていれば閉じる。URL を写せる |

開いたことを伝える文には、**閉じ方まで書く**（開けっぱなしが事故のもと）。

## 確認項目

- [ ] 合言葉が違う URL で、画面も一覧も出ない（404）
- [ ] `/<token>/api/send` のような道が通らない
- [ ] `GET /<token>/api/allow/<id>` で承認されない（405）
- [ ] 一度閉じてもう一度開くと、**前の URL が効かなくなっている**
- [ ] 10 分放っておくと閉じる
- [ ] 要約に `<img onerror=x>` が入っていても、画面でタグとして解釈されない
- [ ] 危ないものが上に出て、同じ危なさなら長く待っているものが上
- [ ] ネットワークに繋がっていない端末で、エラーではなく案内が出る
- [ ] `danger` の項目が一覧に出て、「許す」が出ない
- [ ] `danger` の項目に `POST /<token>/api/allow/<id>` を直接投げても通らない（403）
