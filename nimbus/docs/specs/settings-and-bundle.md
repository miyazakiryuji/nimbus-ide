# 設定タブと、設定のパッケージ配布

## 何を解決するのか

**設定タブ**（T-016）— 設定は `settings.json` の階層・権限モード・モデル・MCP・フックに
散っていて、**いま何が効いているか**を 1 か所で見られない。設定画面で `nimbus.` を
検索する形では「効いているか」が読み取れない。

**配布**（T-043）— スキル・サブエージェント・フックを整えたあと、それを**チームに配る**
手段が無い。「各自 `.claude/` にこれを置いてください」を口で伝えるのは続かない。

## 振る舞い

### 設定タブ（T-016）

サイドバー Nimbus の **「設定」**（既定は折りたたみ）。**いま効いている値**を並べる。

1. **承認ポリシー** — いまのプロファイルと、その広さ（押すと切り替え）
2. **安全** — 秘匿ファイルの遮断 / 送信前の検査 / 読み取りの自動許可 / 承認前の差分
3. **フック** — 件数（押すと組み立て画面）
4. **常に含めるファイル** — 件数（押すとピン留めの管理）
5. **サブエージェントのモデル** — 割り当て件数（押すと割り当て画面）
6. **上限** — 文脈の予算 / 費用の上限 / 同時実行の上限
7. **その他** — 通知 / ホットリロード / 実行ファイル
8. **配る・読み込む**

**編集画面は作り直さない。** 個々の編集はコマンドとして既にあるので、
ここはその入口を集め、いまの値を見せるだけにする。

**行は必ず行き先を持つ。** 値だけの行（2・6・7）も押すと、その設定に絞り込んだ設定画面が開く。
押しても何も起きない行を置かない — 何が押せるのか見分けがつかず、
「壊れている」と受け取られる（実際にそう報告された・T-244）。

> ここは一度、**全部の行が飾りだった**。`actionNode()` はコマンド名を受け取りながら
> `contextValue` に入れるだけで、`TreeItem.command` を設定していなかった。
> 土台の `TreeNode` にコマンドの口が無かったのが原因で、仕様には「押すと切り替え」と
> 書いてあったのに 1 行も押せない状態が続いた。

### 配布（T-043）

- **「設定をまとめて配る」**（`nimbus.exportBundle`）— `.claude/` の
  `skills` / `agents` / `commands` と `settings.json` を **1 枚の JSON** にする
- **ZIP ではなく JSON。** 中身が読めて、差分が取れて、レビューできる形のほうが
  「何を配られたのか」が分かる
- **`settings.local.json` は入れない**（個人の設定）。`.env` / `*.pem` / `*.key` /
  `secrets.*` も名前で弾く
- 名前で弾いただけでは本文に書かれた資格情報は止まらないので、
  **書き出す前に送信前検査と同じ規則で本文を調べる**。見つかったら一度聞く
- **「配られた設定を読み込む」**（`nimbus.importBundle`）— 展開の前に
  「新規 3 · 上書き 1 · 変更なし 2」のように**何が起きるかを出す**
- **既存と中身が違うものは黙って上書きしない。** 「新規だけ入れる」と
  「すべて入れる（上書きあり）」を選ばせる。上書きになるファイル名も出す
- `..` や絶対パスが入った配布物は読み込まない（`.claude/` の外へ書かせない）
- 知らない `version` は読まない（新しい形式を古い Nimbus が中途半端に展開するほうが危ない）

## 設計

- `extensions/nimbus/src/core/bundle.ts` — 何を配れるか・形の検査・展開計画。VS Code 非依存
- `extensions/nimbus/src/bundleCommands.ts` — `.claude/` の走査と読み書き
- `extensions/nimbus/src/settingsView.ts` — 設定タブ（`views/treeView.ts` の土台に載る）

## 決めなかったこと・やらないこと

- **設定タブに編集画面を作らない。** 入口を集めるだけにする。
  同じ編集を 2 か所に持つと、片方だけ直す事故が起きる
- **`~/.claude/`（ユーザー設定）は配布に含めない。** 配るのはプロジェクトのもの。
  個人の設定を配ると、受け取った側の環境を壊す
- **プラグイン形式（`.claude-plugin`）にはしていない。** まず「配れる・読める」を作る。
  cc-DevelopmentTeam への導線は、形が固まってから
- **バージョン管理・更新通知はしない**（T-071 / T-094 の仕事）
