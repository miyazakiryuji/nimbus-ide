# プラグインを見る

入っているプラグインの一覧と、有効／無効の切り替え（T-032）。

## 何を解決するのか

スキルの一覧は入れたが、**そのスキルがどこから来ているか**はプラグイン単位でしか
切り替えられない。「このプラグインを切りたい」と思ったとき、いまは設定ファイルを開いて
`enabledPlugins` を手で書き換えることになる。

## 振る舞い

コマンド「プラグインを見る」（`nimbus.managePlugins`）。

- **入っているものだけ**を一覧に出す。選ぶと、いまの状態の逆を実行する
- **入れるのは別の一覧**（「入れる…」）。目録は数百件あるので、混ぜると切り替えたいものが埋もれる
- 実行の前に「何が起きるか」と**いつ効くか**を出す

### 変えるのは CLI に任せる

読むのは自前、**変えるのは `claude plugin install|enable|disable`**。
取得や検証を持っているのは CLI の側で、設定ファイルを横から書き換えると壊せてしまう。
`claude` が無ければ、そう言って終わる。

### 状態は 4 つ

| 状態 | 意味 | 押すと |
| --- | --- | --- |
| 有効 | 入っていて有効 | 無効にする |
| 無効 | 入っているが無効 | 有効にする |
| 未取得 | 目録にあるだけ | 入れる |
| **設定だけ残っている** | `enabledPlugins` にあるのに入っていない | **入れ直す** |

**4 つめを「無効」と一緒にしない。** 一緒にすると、有効にしても何も起きない理由が
分からなくなる。

**目録に無いが入っているもの**（手で入れた・目録から消えた）も一覧から落とさない。
落とすと「切りたいのに出てこない」になる。

### 効くのはいつか

**その場では効かない。** 変更は次に始めるセッションから効く。動いているセッションは
そのまま — ここを黙ると「切ったのに動いている」と見える。

## 設計

- `extensions/nimbus/src/core/plugins.ts` — 3 つのファイルの突き合わせ（VS Code 非依存）
- `extensions/nimbus/src/plugins.ts` — 読み込みと `claude plugin` の実行

読むファイル（すべて `~/.claude` の下）:
`plugins/installed_plugins.json`（version 2）、`settings.json` の `enabledPlugins`、
`plugins/marketplaces/<名前>/.claude-plugin/marketplace.json`。

## 決めなかったこと・やらないこと

- **設定ファイルの直接編集** — CLI が状態を持っている。横から書くと壊せる
- **プラグインの中身の表示** — `claude plugin details` がある。作り直さない
