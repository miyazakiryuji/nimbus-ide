# セッションの始め方・分けかた・戻しかた

## 何を解決するのか

**テンプレート**（T-148）— よく使う始め方は数種類しかない（調査 / 実装 / レビュー）。
毎回モデルと権限を選び直すのは無駄だし、選び忘れると書き換えてほしくない場面で書き換わる。

**分岐**（T-036）— 「最小の変更で直す」と「作り直す」を**両方見てから**決めたいことがある。
順番に試すと、1 つ目の結果に引きずられる。

**復元**（T-150）— 昨日の続きから始めたい。会話は残っているのに、戻る手段が無い。

## 振る舞い

### テンプレートから始める（T-148）

コマンド **「Nimbus: テンプレートから始める」**（`nimbus.startFromPreset`）。

- 出荷時に 3 つ入っている。**空の状態から始めさせない**（何を作れるか分からないと使われない）
  - **調査（書き換えない）** — `plan` モード。「調べて報告してください。コードは変更しないでください」
  - **実装** — `default` モード
  - **レビュー** — `plan` モード。「指摘は根拠となる行を添えてください」
- 選ぶと指示を聞かれ、ひな形の `{input}` に入る
- **`{input}` が無いひな形でも、入力を捨てない**（末尾に足す）。
  捨てると、書いた指示が消えたことに気づかないまま走り出す
- 追加・削除は「テンプレートを管理」（`nimbus.managePresets`）。同じ名前は 2 つ作れない
- 保存先は `globalState`（プロジェクトをまたいで使う）

### 分岐（T-036）

コマンド **「Nimbus: いまの作業を分岐する（A 案・B 案）」**（`nimbus.branchSession`）。

- 案の数（2 か 3）を選び、案ごとに指示を書く
- **タスクとして作る**ので、それぞれ別の worktree で走り、案どうしが互いを壊さない
- 名前は「いまの作業（A 案）」「…（B 案）」。どれがどの案かが一目で分かる
- 同時実行の上限（`nimbus.tasks.maxConcurrent`）まで順に走る
- **途中でやめたら 1 つも作らない**（半端に走り出すほうが困る）

### 復元（T-150）

コマンド **「Nimbus: 過去のセッションを再開する」**（`nimbus.restoreSession`）。

- **いま開いているフォルダで動いていた記録だけ**を候補にする（別プロジェクトの続きは出さない）
- 新しい順に 30 件。Claude Code が付けたタイトル・ブランチ・終了時刻で選ぶ
- 選ぶと SDK の `resume` で再開する。続きから指示できる

## 設計

- `extensions/nimbus/src/core/sessionPresets.ts` — ひな形の適用・重複の排除・分岐の名前。VS Code 非依存
- `extensions/nimbus/src/sessionLifecycle.ts` — 選ばせる UI と、記録の走査
- `extensions/nimbus/src/extension.ts` — コマンドとセッションの起動

### バックアップは自前で取らない

T-150 は「自動バックアップと復元」だったが、**バックアップは Claude Code 本体が既に取っている**
（`~/.claude/projects/**` の JSONL）。Nimbus が別に保存すると二重管理になり、
どちらが正かが分からなくなる。ここは「読んで、選んで、再開する」だけにした。
記録の読み取りは T-034（横断検索）と同じ `core/transcripts.ts` を使っている。

## 受け入れ条件

- [x] 出荷時のテンプレートが 3 つ入っている（単体テスト）
- [x] 調査・レビューは書き換えさせない（`plan`）（単体テスト）
- [x] `{input}` が無いひな形でも入力を捨てない（単体テスト）
- [x] 同じ名前のテンプレートを 2 つ作らない（単体テスト）
- [x] 分岐の名前が A 案・B 案になり、5 を超えたら数字に落ちる（単体テスト）
- [ ] 画面確認: テンプレートから始めて `plan` モードで動く
- [ ] 画面確認: 分岐して 2 つのタスクが板に並ぶ
- [ ] 画面確認: 過去のセッションを再開して続きから指示できる

## 決めなかったこと・やらないこと

- **分岐の結果を横並びで比較する画面は作っていない。** 別々の worktree に分かれるので、
  比較は Git の差分で見るのが素直。専用の比較画面は、必要になってから
- **バックアップは自前で取らない**（上記）
- **テンプレートにツールの許可リストを持たせていない。** 権限モードで足りる。
  細かい許可は T-028 / T-038 のルール側の仕事
