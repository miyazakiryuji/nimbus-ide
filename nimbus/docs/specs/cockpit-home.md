# コックピットのタブ（束）と Home

**タスク**: T-314 / **すり合わせ**: 2026-08-25 に利用者と合意 /
**実装**: `src/core/sessionGroups.ts`（判断）・`src/groupStore.ts`（読み書き）・
UI 配線は未（下記） / **テスト**: `sessionGroups.test.ts`（10 件）・`groupStore.test.ts`（4 件）

## 合意した形

1. **タブ = Nimbus のセッションを入れる自由な束。** フォルダやタスク板とは結合しない。
   好きに作って、好きなセッションを入れる
2. **サイドバーの縮小版コックピットが Home。** タブごとの束で全セッションと状態が見え、
   セッションを押すと**その場で会話に切り替わる**（家アイコンで Home へ戻る）
3. **狭いサイドバーでは、セッションの列を並べない。** 会話中の切り替えは
   **ハンバーガー（≡）に畳み**、押すと Home（束一覧）が出る。
   広い面（エディタタブ・全画面）では 2 段（上にタブ列、下にそのタブのセッション列）
4. **タブもセッションも改名できる。** セッションの改名は T-313（別セッション実装中）の
   受け持ちで、ここでは**重複させない**。タブの改名がこちら

```
┌─ 縮小版（サイドバー）= Home ─────────┐      ┌─ 会話（狭い）──────────────┐
│ ▾ ■ 作業                      [+]   │      │ ≡  ▶ 調査する        ⌂    │
│     ▶ 調査する            作業中    │  ⇄   │ （会話）                   │
│ ▾ ■ ログイン改修          ✎  [+]   │      └────────────────────────────┘
│     ! 実装する          許可待ち    │      ≡ / ⌂ で Home へ
│ ［新しいタブ］                      │
└─────────────────────────────────────┘
広い面（エディタタブ・全画面）: [■作業][■ログイン改修] ← タブ列
                                [▶調査][!実装]         ← セッション列
```

## 決めたこと

- **既定タブ「作業」**にどの束にも入っていないセッションが入る。タブという概念が増えても、
  既存のセッションが行き場を失わない（後方互換）。既定タブは**消せない・改名できない** —
  消せると「未所属」という 2 つ目の行き場が要る
- **タブを消しても、中のセッションは既定タブへ戻る。** 束は持ち主ではない。
  畳んだらセッションごと消える、は軽い操作に載せる結果として重すぎる（人間工学 E3）
- **タブ名**: 空白だけは断る・30 文字を超えたら**切らずに断る**（黙って切ると
  「付けた名前と違う」が起きる）・同名は許す（禁止すると「作業 2」を強いる）
- **空のタブも Home に出す。** 作った直後に見えないと「作れたのか」が分からない（T-244）

## 永続化（groups.json）

台帳（1 セッション 1 ファイル）と違い、**1 ファイル**。タブの定義と所属は
作る・改名・入れ替えのときにしか変わらず、書き込みの性格が違う。

- 形: `{ groups: [{id,name,createdAt,order}], members: {sessionId: groupId} }`
- 置き場所: 台帳と同じ `globalStorage/idris.nimbus/`
- 書きかたは台帳と同じ **別名 → rename**（不可分）。同一ウィンドウ内の連続更新は
  **読み→変換→書きを直列化**して互いの上書きを防ぐ（テストで固定）。
  ウィンドウをまたぐ同時書きは後勝ちを受け入れる — 賭けているのはタブ名と所属だけで、
  セッション本体は台帳にある（負けても取り返しがつく）
- 壊れた JSON は**形として通る分だけ拾う**。定義の消えたタブへの所属は既定タブとして扱う
  （groups.json が半端でも Home が開かなくなることはない）
- 消えたセッションの所属は掃除する（`pruneMembers` — 台帳の `sweep()` と同じ発想）

## 決めなかったこと・やらないこと

- **タブの並び替え UI は初回では作らない**（`order` は持っているので、要るなら足すだけ）
- **Herdr のセッションは束に入れない**（読むだけの一覧に留める・T-279 の方針のまま）
- **タブごとの一括操作（全部止める等）は載せない** — 束は見るための単位で、
  操作の単位にすると誤爆が束単位になる
