# ターミナルを並べる

好きな数のターミナルを、一度に並べる（T-014）。

## 何を解決するのか

複数のエージェントを同時に走らせると、**出力を同時に見たくなる**。
VS Code は分割できるが、何枚並べるかは自分で決めることになり、
4 枚に割ってから「細すぎて読めない」と気づく。

## 振る舞い

コマンド「ターミナルを並べる」（`nimbus.splitTerminals`）。

- 枚数を選ぶ（2 / 3 / 4 / 6、それ以外は打てる）
- **1 枚目だけ普通に作り、2 枚目からはその隣に割る** — 1 つのグループに収まり、まとめて閉じられる
- **フォルダが複数開いていれば、フォルダごとに 1 枚**。名前もフォルダ名にする
  （どの窓がどのプロジェクトか分からなくなるのが、複数フォルダでいちばん困ること）

### 何枚まで並べるか

**1 枚 40 桁**を下回ると読めなくなるので、そこで頭打ちにする。
80 桁は「本来の 1 行」だが、それを守ると 2 枚しか置けない。ログを流し見るだけなら
40 桁で足りる（折り返しても、どれが動いているかは分かる）。

- **減らしたときは、並べる前に言う。** 黙って減らさない
- **「頼んだ枚数のまま並べる」道は残す。** 読めないと分かったうえで選ぶのは本人の自由
- 枚数がフォルダ数に足りないときは、**出ていないフォルダを名指しする**

幅は `Terminal.dimensions` から取る。これは proposed API なので
`enabledApiProposals` に `terminalDimensions` を足した（`testObserver` と同じ枠）。
**取れないときは 4 枚まで**（画面の広さを勝手に決めない）。

## 設計

- `extensions/nimbus/src/core/terminalLayout.ts` — 枚数と割り当ての決定（VS Code 非依存）
- `extensions/nimbus/src/terminalLayout.ts` — 幅の取得と、実際の分割

## 受け入れ条件

- [x] 好きな枚数を並べられる（4 枚に限らない）
- [x] 幅から読める枚数を出し、足りなければ減らして**言う**
- [x] 頼んだ枚数のまま並べる道を残す
- [x] フォルダが複数なら、フォルダごとに 1 枚・フォルダ名で呼ぶ
- [x] 出ていないフォルダを名指しする
- [x] 幅が取れないときは 4 枚まで
- [x] 画面確認 — GUI 28（頼んだ枚数だけ実際に増える）

単体テスト: `extensions/nimbus/src/test/terminalLayout.test.ts`（10 件）

## 決めなかったこと・やらないこと

- **任意のグリッド（2×3 など）** — VS Code のターミナルは 1 グループが横並び。
  縦横に組むには中核の変更が要る。**横に並べるだけで、同時に見るという目的は足りる**
- **枚数の記憶** — 次に開くときの枚数は場面で変わる。決め打ちしない
