# いまのようす（区切りと待ち時間）

続けすぎと、待ち時間の使い道をすすめる（T-089 / T-053）。T-336 で**待ち時間コンパス**が乗った。

## 何を解決するのか

エージェントを回していると、**待っている時間**と**ぶっ通しの時間**が両方増える。
どちらも自分では気づけない（画面を見ていると時間の感覚が消える）。

## 振る舞い

コマンド「いまのようすを見る」（`nimbus.openRhythm`）。

- 続けている時間・走っているタスク数・承認待ちの数を出す
- すすめかた
  - **90 分以上続けていたら**「一度区切りませんか」
  - 走っているものがあり、**承認待ちが無ければ**「待っている間に別の作業へ移れます」
  - 承認待ちがあるときは、待ちの話をしない。**そこは人の番**なので、そちらを先に
  - 休憩のほうが待ち時間より優先
- **一度すすめたら 45 分は黙る。** 同じことを繰り返す通知は、それ自体が無視される訓練になる
- 起点は「Nimbus を開いた時刻」。セッションをまたいで数えると、寝ている間まで
  「続けている」ことになる

## 待ち時間コンパス（T-336）

開いた 1 枚の**頭に、いま見るべきものを 1 つの短い状態で出す**:

| 判定 | いつ |
| --- | --- |
| **人の番** | 承認待ちがある（エージェントはそこで止まっている）。何も走っていないときも（指示を出す番） |
| **デバッグを見る** | 失敗（error）で止まったセッションがある。走らせ直す前に原因を先に |
| **区切る** | 90 分以上続けている |
| **別作業へ** | 走っているものを待っている（結果は状態の帯に出る） |

- 優先順は上の表の順（承認 → 失敗 → 続けすぎ → 待ち）。**1 つしか出さない** — 並べたら状態でなく一覧になる
- suggest() の「45 分黙る」に**縛られない**。コンパスは自分で開いたときにしか見えないので、押しつけにならない
- 入口はコックピットのタイトル（コンパスのアイコン `resources/nimbus-compass.svg`・原本は
  `icon-concepts/2026-08-26/`）。全画面（エディタタブ）のタイトルにも同じものを置く
- 約束どおり**足さない**もの: 割り込み通知・音・常時動くアニメーション・専用サイドバー
