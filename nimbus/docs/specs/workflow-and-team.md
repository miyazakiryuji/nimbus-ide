# 流れに沿って進める・解説モード・チーム設定の同期

## 何を解決するのか

**流れ**（T-149）— 「調査 → 実装 → テスト → レビュー」は毎回同じなのに、
毎回手で 4 回頼んでいる。途中で 1 つ飛ばしても気づかない。

**解説モード**（T-045）— なぜそのファイルを読んだのか、なぜその設計にしたのかが
見えないと、判断の良し悪しを確かめられない。画面共有すればそのまま教材になる。

**チーム設定**（T-049）— T-043 で「書き出して配る」はできたが、
配る側が更新したときに、受け取った側が気づけない。

## 振る舞い

### 流れに沿って進める（T-149）

コマンド **「Nimbus: 流れに沿って進める」**（`nimbus.runWorkflow`）。出荷時に 2 本:

| 流れ | 段 |
| --- | --- |
| 調査 → 実装 → テスト → レビュー | 調査 / 実装 / テスト / レビュー |
| 不具合を直す | 再現 / 原因 / 修正 / 回帰 |

- 最初の段に渡すことを聞いて始まる。以降は段ごとに送る
- **自動では次へ進まない。** 段が終わると「次の段へ」を出す。
  段の切れ目で人が確認できることが、この機能の値打ち
- 位置を必ず出す（`調査 → … — 2/4 実装`）。**流れの中の位置が見えないと、飛ばしても気づかない**
- 最後の段だけは確認を挟まない（そこで終わるので）

各段の型に効かせたこと:

- **調査の段は「調べるだけ」「変更しないでください」「実装に進んでよいかを述べてください」。**
  言わせないと、調査のつもりで実装まで進む
- **実装の段は「見当が違うと分かったら、直さずに止めて報告」**
- **テストの段は「通ったログを示す。通っていないなら通っていないと言う」**
- レビューの段は「直すかどうかは私が決めます」

### 解説モード（T-045）

コマンド **「Nimbus: 解説モードにする」**（`nimbus.explainMode`）。

「何をしたか」ではなく **「なぜそうしたか」** を求める:
読む前に「なぜそれを読むのか」、設計を選ぶときは「選ばなかった案と、その理由」、
詰まったら「何が分からないのか」。**1 行ずつで十分**と明示する（長い解説は邪魔になる）。

### チーム設定の同期（T-049）

コマンド **「Nimbus: チーム設定を取り込む」**（`nimbus.syncTeam`）。

- 置き場所は既定で `.claude/team-bundle.json`（設定 `nimbus.team.bundlePath`）
- **リポジトリにコミットされている前提。** 誰がいつ何を変えたかは Git が持っているので、
  Nimbus が履歴を持つ必要がない
- 差分があるときだけ知らせる。中身は T-043 と同じ形式・同じ検査
- **上書きになるものがあれば、そう言ってから聞く**

## 設計

- `extensions/nimbus/src/core/workflow.ts` — 流れの定義と位置の計算。VS Code 非依存
- `extensions/nimbus/src/bundleCommands.ts` — `syncTeamBundle()`（T-043 の仕組みを再利用）
- `extensions/nimbus/src/extension.ts` — コマンドと進行状態

進行中の流れは **1 本だけ**持つ。同時に 2 本走らせると、どちらの段にいるか追えなくなる。

## 受け入れ条件

- [x] 出荷時の流れが 2 本、段ごとに名前が付いている（単体テスト）
- [x] 調査の段が「調べるだけ」「変更しない」「進んでよいか述べる」を含む（単体テスト）
- [x] テストの段が「通ったログ」を求め、通っていなければ言わせる（単体テスト）
- [x] 段を進めると位置が動き、最後で終わる（単体テスト）
- [x] 最後の段だけ確認を挟まない（単体テスト）
- [x] 解説モードが「なぜ」を求め、長い説明は求めない（単体テスト）
- [ ] 画面確認: 流れを始めて 2 段目まで進む
- [ ] 画面確認: チーム設定の差分が知らされる

## 決めなかったこと・やらないこと

- **自動で全段を走らせない。** 走らせられるようにすると、確認のために作った
  段の切れ目が意味を失う
- **流れを利用者が定義できるようにはしていない。** まず 2 本で足りるかを見る。
  定義を増やせるようにすると「どの流れにいるか」が余計に分かりにくくなる
- **チーム設定を起動時に自動で取り込まない。** 知らせるところまで。
  黙って設定が変わるのが一番困る
