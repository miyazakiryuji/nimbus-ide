# 走っている最中に繰り返しに気づく（T-237）

同じ指示を毎回書いているなら、それは CLAUDE.md に書けば済む話。
けれど**気づくのは、たいてい後日**（記録を読み返したとき）で、
そのときには「そういえば書いていたな」で終わってしまう。

**3 回目を書いているその場**で気づけないと、CLAUDE.md に足す機会は来ない。

## 振る舞い

指示を送るたびに、そのセッションで書いた指示を数える。
同じ内容を 3 回書いた時点で、一度だけ聞く:

```
同じ指示を 3 回書いています。CLAUDE.md に足しますか？
  コミットメッセージは日本語で書いてください。
```

**「CLAUDE.md に足す」**を押すと、既存の導線（`nimbus.promoteInstruction`）に繋がる。

## 実装

- 判定は既存の `core/repeatedInstructions.ts`（T-041 で作られたもの）を**そのまま使う**
- `extensions/nimbus/src/sessionRepeats.ts` — いつ聞くかだけを持つ
- テスト: `extensions/nimbus/src/test/sessionRepeats.test.ts`

## 決めたこと

**判定を作り直さない。** 過去の記録から探す仕組みは既にある。違うのは「いつ数えるか」だけなので、
同じ純関数に同じ入力（このセッションの指示）を渡す。**同じ入力に同じ答えが返ることが大事。**

**同じものは一度しか勧めない。** 4 回目・5 回目でまた聞かれると、通知ごと切られる。

**新しいセッションで数え直す。** 「このセッションで繰り返している」が単位。
別の話題に移ったのに前の繰り返しを数え続けても意味が無い。

**送信が確定したものだけを数える。** 送信前検査（T-075）で止めたものは数えない。

## 確認すること

- [ ] 同じ指示を 3 回送ると聞かれる
- [ ] 同じ内容で 4 回目を送っても、もう聞かれない
- [ ] 「CLAUDE.md に足す」で既存の追記フローに入る
- [ ] 新しいセッションを始めると数え直される
- [ ] `nimbus.claudeMd.suggestRepeats` を `false` にすると聞かれない

## 残っていること

- 言い回しが違う同じ指示は拾えない（正規化は表記ゆれまで。意味では見ていない）
- セッションをまたいだ繰り返しは、これまでどおり記録から探す側（T-041）の担当
