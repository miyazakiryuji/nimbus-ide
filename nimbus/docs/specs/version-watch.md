# Claude Code の更新に気づく（T-094）

新しいフックやツールが増えても、**増えたことに気づく機会が無い**。
知らないまま古いやり方を続けるのが、いちばんもったいない。

バージョン番号だけでは「何が増えたか」は分からない。けれど **init が毎回渡してくる
ツール・スラッシュコマンド・スキル・サブエージェントの一覧**を覚えておけば、
差分は機械的に出せる。**推測ではなく、実際に増えたものだけ**を言える。

## 振る舞い

セッションが始まるたびに一覧を覚え直し、前回から増えていたら 1 回だけ知らせる:

```
Claude Code が 2.1.0 → 2.2.0 に上がりました
  ツール: Skill
  スラッシュコマンド: /loop
  サブエージェント: reviewer
```

**「使いどころを聞く」**を押すと、増えたものを並べて
「このプロジェクトで実際に役立ちそうなものがあれば教えて」と聞く。
そこに **「知らないものは知らないと言ってください」** を必ず入れる。

## 実装

- `extensions/nimbus/src/core/versionWatch.ts` — 差分と文面（純関数）
- `extensions/nimbus/src/versionWatch.ts` — `globalState` への記憶と通知
- テスト: `extensions/nimbus/src/test/versionWatch.test.ts`

## 決めたこと

**バージョン番号だけでは知らせない**（増えたものが無ければ 1 行で終わる）。
「上がりました」だけの通知は、読む価値が無い。

**増えたものだけを見る。** 消えたものは騒ぐ理由が無い（プロジェクトの設定で
スキルが外れることは普通にある）。

**初回は黙って覚えるだけ。** 比べる相手がいないのに「増えました」とは言えない。

**「知らないものは知らないと言って」を必ず入れる。** 学習時点より新しい機能について
それらしい説明を作られると、いちばん困る。**この通知は、その事故が起きやすい場所**。

**記憶は `globalState`。** Claude Code の更新はマシン単位の話で、リポジトリごとではない。

## 確認すること

- [ ] 初回のセッションでは何も出ない
- [ ] Claude Code を更新したあとのセッションで、バージョンの変化が出る
- [ ] 新しいスキルを足したあとのセッションで、その名前が出る
- [ ] 何も変わっていなければ何も出ない
- [ ] 「使いどころを聞く」でコックピットに一覧が送られる

## 残っていること

- 変更履歴（changelog）は読んでいない。**手元で見える差分だけ**
- 設定（`settings.json` のフック種別）の増減は見ていない
