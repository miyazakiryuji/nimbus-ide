## NG 記録と再実施

- ESLint「render 中の ref 書き込み」「effect 内の同期 setState」: 抑制せず構造で解決（root を prop 化し `key` で再マウント、ref 同期は effect へ）。非同期取得の 1 件のみ既存 3 ビューと同じ根拠コメント付きで disable
- FileService の初期実装は `mkdir` を実体検証より先に行っており、**途中に外向き symlink があるとルート外にディレクトリを作れる**穴があった → 実在する最近接祖先を先に realpath 検証する順序へ修正し、テストで外部にディレクトリが作られないことを確認
- **D-1 初回 NG（スクリーンショット検品が発見した実バグ 2 件）**: エクスプローラーが「フォルダを開いてください」の空表示のまま、かつステータスバーが「接続未確認」になっていた。原因は**セッションイベントの購読がチャット画面の内部にあった**こと — コックピット以外のビューを開いている間はイベントが届かず、エクスプローラーの対象ディレクトリも課金モードも決まらない。購読と再アタッチを `useSessionSync` として App レベルへ引き上げ（ボード/レビュー/診断にも波及する修正）、再撮影で解消を確認
