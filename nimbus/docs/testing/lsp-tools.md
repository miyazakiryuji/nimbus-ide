## 3. 実際に効いているかの確かめ方

「定義が返る」だけでは足りない。**grep に逃げずにこちらを使うか**が本題なので、
同じ問い（例:「`normalizeSdkMessage` を呼んでいるところを全部挙げて」）を
`nimbus.lsp.enabled` の on / off で 1 回ずつ流し、読んだファイル数とツール呼び出しの回数を比べる。
