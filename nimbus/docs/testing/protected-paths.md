# 読ませたくないファイルの指定 確認チェックリスト（T-155）

仕様: [`nimbus/docs/specs/protected-paths.md`](../specs/protected-paths.md)

判定ロジック（glob の当たり判定）は `core/secrets.ts` 側のテストで押さえてある。
ここは画面の操作なので、確認は目視で行う。

## 画面確認（未実施）

コマンドパレット → 「Nimbus: 読ませたくないファイルを指定する」。

- [ ] A-1 設定が空の状態で開くと、既定の一覧が「既定の一覧（読み取り専用）」として並ぶ
- [ ] A-2 `!` 始まりの項目が「例外（読める）」と表示される
- [ ] A-3 既定のまま項目を選ぶと「先に既定を取り込んでください」と案内が出て、消えない
- [ ] A-4 「パターンを足す」で `**/secrets/**` を入れると、設定 `nimbus.safety.protectedPaths` に入る
- [ ] A-5 A-4 のあと開き直すと「自分の設定」として並び、既定の項目も含まれている
- [ ] A-6 項目を選ぶと確認モーダルが出て、「外す」を押すと一覧から消える
- [ ] A-7 モーダルを Esc で閉じると外れない
- [ ] A-8 「既定に戻す」で設定が空になり、また読み取り専用の表示に戻る
- [ ] A-9 実際に `.env` を Claude に読ませようとすると、承認を出さずに拒否される（safety 側の確認）
