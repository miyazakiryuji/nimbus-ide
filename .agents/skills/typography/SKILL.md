# 文字 — 日本語で読む前提で決める

`design-philosophy` の型ラムが決めるのは**役割**（`body1` か `label2` か、`regular` か
`semiBold` か）。それは正しいが、**どのフォントで出るか**は決めていない。
upstream は英語で読む前提なので、そこは書かれていない。

Nimbus は表示言語を日本語にした（T-245）。**役割が正しくても、積みが日本語を持っていなければ
読みにくい。** ここはその抜けを埋める。

## 原則

### T1 積みに日本語が入っているか（フォールバックに任せない）

> **問い：** *この積みは、日本語の字を**名指しで**持っているか。*

持っていなければ、ブラウザは**字ごとに**別のフォントへ落とす。落ちた先は OS 任せで、
版が変われば変わる。同じ画面の英数と日本語が別の設計のフォントで並ぶので、
**x ハイトも太さも合わない**。

**落ちているとき（実測・macOS）**

- 等幅の既定 `Menlo, Monaco, 'Courier New', monospace` には**日本語が 1 文字も無い**。
  日本語は Hiragino Sans（**プロポーショナル**）に落ちるので、
  ツール出力の表や図がずれる。**macOS には日本語の等幅がプリインストールされていない**
  （Osaka-Mono は現行 OS から消えた）
- UI の既定 `-apple-system, BlinkMacSystemFont, sans-serif` も日本語を名指ししていない。
  macOS では Hiragino に落ちて実用になるが、Linux（`system-ui, Ubuntu, Droid Sans`）では
  保証が無い

**手当て：** 積みの末尾に日本語の家族を**名指しで**足す。同梱するかは別の判断
（ライセンスと容量）。決めたら、**なぜその順なのか**を仕様に残す — 積みの順は
後から見て理由が分からなくなる典型。

### T2 太さは実体か、合成か

> **問い：** *その `600` は、フォントが持っている太さか。ブラウザが作った太さか。*

家族を名指ししていないと、ブラウザは**合成太字（faux bold）**を作る。輪郭を太らせるだけなので、
画数の多い漢字が小さい字で**つぶれる**。

Hiragino Sans は **W0〜W9** を持っているので、名指しすれば `semiBold` が実体で出る。
名指ししないとその資産を使えない。

**手当て：** 太さを使う面では家族を名指しする。型ラムは 2 ウェイト（400 / 600）だけなので、
その 2 つが実体で出ることだけ確かめればよい。

### T3 行間は、日本語のぶんだけ広く取る

> **問い：** *この行間は、英数で決めた値をそのまま日本語に当てていないか。*

日本語は仮想ボディいっぱいに字が入るので、同じ行間でも英数より詰まって見える。
本文として読ませる面は **1.5 以上**を目安にする。

**落ちているとき：** エディタの既定 `lineHeight: 0`（自動）は、**英数のフォントから**計算する。
webview 側は自分で決められるので、そこは決める。

### T4 和欧が混ざる行を、同じ格に見せる

> **問い：** *`Claude Code を起動` の英数と日本語が、同じ大きさに見えるか。*

同じ `font-size` でも、欧文と和文では見た目の大きさが違う（和文のほうが大きく見える）。
1 行に混ざるとどちらかが浮く。

**手当て：** 大きさを別々にいじらない（役割が壊れる）。**積みの順**で揃える —
先に来る家族の字面に合うものを後ろに置く。それでも合わなければ、
その面だけ役割を 1 段変える（`body1` → `body2`）ほうが、数値をいじるより安全。

## レビューでやる手順

1. その面の積みを読む。**日本語の家族が名指しされているか**（T1）
2. 太さを使っているなら、それが実体か（T2）
3. 本文として読ませる面の行間が 1.5 以上か（T3）
4. 和欧が混ざる行を実際に出して見る（T4）

**数えた結果は、数字ではなく積みで書く。**
「字が小さい」ではなく「**等幅の積みに日本語が無く、プロポーショナルに落ちている**」と書く。

## 語彙

| ❌ こう言わない | ✅ こう言う | 原則 |
| --- | --- | --- |
| 「日本語が読みにくい」 | 「**積みに日本語が無く、字ごとに別フォントへ落ちている**」 | T1 |

| 「行間を広げて」 | 「**英数で決めた行間を日本語に当てている**」 | T3 |
